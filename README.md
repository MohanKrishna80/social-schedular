# 🚀 Social Media Scheduler

A full-stack social media management platform that helps users create, schedule, and manage posts across multiple social media platforms from a single dashboard.

## 🌟 Features

### 🔐 Authentication
- User Registration & Login
- JWT Authentication
- Protected Routes
- Secure Password Hashing

### 📱 Social Account Management
- Connect Multiple Social Media Accounts
- Manage Connected Platforms
- View Account Status

### ✍️ AI-Powered Content Creation
- Generate Social Media Posts using AI
- Content Suggestions
- Improve Existing Content

### 📅 Post Scheduling
- Schedule Posts for Future Publishing
- Manage Scheduled Posts
- Edit or Delete Scheduled Posts
- Automatic Publishing System

### 📊 Dashboard Analytics
- Total Scheduled Posts
- Published Posts
- Connected Accounts
- Recent Activity Tracking

### ☁️ Media Uploads
- Upload Images
- Cloud Storage Integration
- Media Preview Support

### 🎨 Modern UI
- Responsive Design
- Clean Dashboard Layout
- Interactive Components
- Smooth User Experience

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/social-media-scheduler.git
cd social-media-scheduler
```

### Backend Setup

```bash
cd server
npm install
```

Create `.env`

```env
PORT=3000
MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_jwt_secret

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

GEMINI_API_KEY=your_gemini_api_key
```

Start Backend

```bash
npm run dev
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```
